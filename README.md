# 🛒 Walmart Sales Analytics & 12-Week Forecasting

An interactive Streamlit dashboard for analyzing Walmart weekly sales, identifying sales patterns and economic factors, and forecasting future sales across 45 stores.

## 📌 Project Overview

This project analyzes **6,435 Walmart sales records** across **45 stores** and **143 weeks** of historical data.

The dashboard provides:

- 📊 Sales performance analysis
- 📅 Trend and seasonality analysis
- 🎉 Holiday vs non-holiday analysis
- 🌡️ Temperature analysis
- ⛽ Fuel price analysis
- 📈 CPI and unemployment analysis
- 🏪 Store performance comparison
- 🔍 Statistical analysis and correlations
- 🔮 12-week sales forecasting
